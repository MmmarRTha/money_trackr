# AGENTS.md

money-trackr personal finance app. Laravel 13 backend + Inertia/Vue 3/TypeScript SPA frontend. Auth is Fortify (+ passkeys), not Breeze scaffolding. UI: Tailwind v4, shadcn-vue (reka-ui), lucide icons.

## Commands

Run the full composer script chain before finishing: `composer test` = config:clear → `composer lint:check` (pint) → `composer types:check` (phpstan, **level 7**) → `php artisan test` (Pest). `composer ci:check` additionally runs the frontend `pnpm lint:check`, `pnpm format:check`, `pnpm types:check` (vue-tsc --noEmit).

- `composer lint` — pint auto-fix (default `composer lint:check`).
- `composer types:check` — phpstan, covers `app/ bootstrap/app.php config/ database/ routes/`.
- `pnpm lint` / `pnpm format` / `pnpm dev` — frontend fixers / vite dev server.
- `php artisan dev` (i.e. `composer dev`) — Laravel dev server.
- Single test: `php artisan test tests/Feature/DashboardTest.php` or `vendor/bin/pest`.

PHPunit tests use in-memory sqlite (phpunit.xml); local `.env` uses sqlite too — no DB server needed.

## Wayfinder generated code — critical

`resources/js/routes/**`, `resources/js/actions/**`, `resources/js/wayfinder/**` are **generated by the wayfinder Vite plugin** and gitignored. They are the TS mirror of all server routes/controllers.

- Never hand-edit these files.
- After adding/changing a route or controller, regenerate via `pnpm dev` or `pnpm build`, otherwise `pnpm types:check` (vue-tsc) and editor intellisense break.
- When a controller file changes, both the Laravel side and its generated `actions/` type are used by the frontend.

## Architecture / Inertia conventions

- App entrypoint: `resources/js/app.ts`. Inertia layout is chosen by page-name prefix: `auth/*` → AuthLayout, `settings/*` → `[AppLayout, SettingsLayout]`, `Welcome` → null, any other top-level page → AppLayout automatically. No per-page layout import needed for normal pages.
- Pages live in `resources/js/pages/**` (`auth/`, `settings/`).
- Components: `resources/js/components` (app-level) + `resources/js/components/ui` (shadcn-vue, regenerated, prettier-ignored).
- Route model: `Route::resource('budgets', BudgetController::class)` under `['auth','verified']`; `budgets` table uses `softDeletes`.
- **Budgets are Blade-only, deliberately.** All `BudgetController` resource endpoints return Blade views under `resources/views/budgets/` (e.g. `index`, `create`) backed by Blade components like `app/View/Components/BudgetForm.php`. The budget UI is fully static with no interactive/stateful features, so it does **not** use Inertia/Vue — keep it in Blade; don't convert it to Vue pages or add JS interactivity.

## Style / misc

- Code style is enforced by pint (Laravel preset), prettier (4-space indent, single quotes, semicolons, `prettier-plugin-tailwindcss`), and eslint — the `test`/`ci:check` gates fail if these don't pass. Match existing formatting.
- Import aliases: `@/` → `resources/js` (`components.json`).
- `.npmrc` sets `ignore-scripts=true`.

## Known WIP / gotcha

The rest of the app is Inertia/Vue, but budgets are intentionally Blade-only (see above) — this is not a migration-in-progress.
